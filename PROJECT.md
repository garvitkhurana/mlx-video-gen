# video-gen: Open-source Video Generation Feed

## Goal
Build a feed of AI-generated videos using free, open-source models. Generate short promotional/ad-style videos, display them in a web feed, and iterate on prompts.

## Constraints
- Open-source models only (no paid APIs)
- Local/self-hosted inference preferred
- Start with MVP: generate videos, build simple feed UI
- Focus on speed and iteration to test concept

## Non-goals
- Production-scale infrastructure (yet)
- Complex video editing/effects
- Monetization or deployment
- Multi-user platform
